Linux, Docker, Windows Server, SvelteKit y React también fueron indicados por
Oscar en esta conversación. SvelteKit y Windows Server aparecen como experiencia
personal; esta revisión no encontró un proyecto público concreto que permita
atribuirles esas tecnologías en la tabla de repositorios. La terminal es arte
vectorial ilustrativo, no una captura de un servidor o una ejecución de comandos.

Se conservan las bases de Discord, los proyectos en Go y los créditos de
`os_multijob` de la selección anterior. Los forks de terceros no se presentan como
proyectos propios. No se muestran estrellas, versiones, métricas de actividad o
porcentajes de experiencia que requieran actualización continua.
